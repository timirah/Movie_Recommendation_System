# Movie Recommendation System

## Overview
This project is a **Movie Recommendation System** built with **Collaborative Filtering**.  
It predicts what movies a user might enjoy based on ratings from similar users.

---

## Features
- User–movie rating matrix
- Collaborative filtering (user-based & item-based)
- Personalized movie recommendations
- Works with larger datasets like **MovieLens**
